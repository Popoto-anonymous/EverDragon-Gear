This gear aims to add Dragoon value and make it so you can infinitely goon if you have the SC option of Gear effects in Dragoon on.
Gear is slightly better than vanilla (for the most part) adds 5% HP per turn as 10% was too high, 25 -> 50 Mp per turn to keep you magically going,
and 100 SP per turn to keep you Goonin. 

Some gear adds hidden benefits like a speed bonus or accuracy bonus, while the accessory adds a small to large power boost. Cost is effectively:

300 per piece for low tier
600 per piece for mid tier
900 per piece for final tier
